# School Management Database

## Project Overview
This project is a MySQL database designed to organize and manage school-related information, including student, teacher, and subject records.

## Database Tables
- **Students:** Student IDs, names, gender, level, academic track, email, and GPA.
- **Teachers:** Teacher IDs, names, email addresses, and office numbers.
- **Subjects:** Subject IDs and subject names.

## Features
- Database and table creation
- Inserting sample records
- Retrieving and sorting student data
- Using column aliases
- Updating student and teacher information
- Renaming a table

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

*Note: This project uses sample data for educational purposes.*
